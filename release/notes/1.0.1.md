TruckCraft 1.0.1 targets ETS2 1.62.x, ATS 1.62.x, and save format 105.

- **Windows x64** can download and install future signed updates through **Check for updates**. TruckCraft asks before restarting and can recover the previous executable if the update fails to start. Download 1.0.1 manually once to get the updater.
- **Linux** can receive updates through signed APT, DNF, pacman, and Flatpak feeds. Add the appropriate source once to update through your package manager. [Linux setup](https://github.com/chrissts/TruckCraft#linux-updates)
- Builds without in-app installation still show the available version and link to GitHub Releases.
- Updated the save decoder and file-dialog dependencies.
