TruckCraft 1.0 targets ETS2 1.62.x, ATS 1.62.x, and save format 105.

- Edit your account balance, headquarters, fleet, and market offers. Large balances retain their exact value.
- Create a fresh local save from an installed game. Load it in the simulator, choose a headquarters city, and save again before editing.
- Review staged edits, use Undo or Redo, and recover a backup into a separate profile.
- Edit active Coach journeys in ETS2 and Road Trip cars in ATS when the required journey data is present.
- Use **Check for updates** to compare versions and open the GitHub release page for a manual download.
