# Supplemental license notices

This directory retains the notices from TruckCraft's earlier distribution for
locked Rust dependencies whose registry archives omit the license text.
The packager includes the notices for dependencies used by each build.
It reads font-specific notices directly from the embedded-font crate.

The toolchain notices come from Rust 1.100.0 and the MinGW-w64 runtime used by
the Windows GNU build. Package builds retain the Rust standard library notice
on all platforms and the MinGW-w64 notice on Windows.
